 跨境电商网络环境搭建教程

本教程为傻瓜式操作指南，旨在帮助您从零开始搭建纯净的跨境电商网络环境。请严格按照步骤及配图进行操作。

---

## 一、 前期准备工作

### 1.1 中转节点购买及准备

1. **注册阿里云**
   访问 [阿里云官网](https://www.aliyun.com/minisite/goods?userCode=ou12hhzv) 进行注册。
   ![图1-跳转注册页面](图1_注册页面.png)

2. **登录账号**
   使用手机号加验证码，或使用支付宝/淘宝扫码快捷登录。
   ![图2-登录界面](图2_登录界面.png)

3. **实名认证与购买**
   根据引导完成实名认证（个人或企业均可）。完成后，依次点击：**产品 —> 计算 —> 轻量应用服务器**。
   ![图3-选择轻量应用服务器](图3_选择轻量应用服务器.png)
   点击“立即购买”。

4. **服务器配置选择**
   请按照以下参数进行选择：
   * **套餐类型**：通用型（点击“更多实例”按需选择。5人以内团队推荐 2u1G）。
   * **系统镜像**：选择 **Ubuntu**，版本建议 **22.04** 或以上。
   * **地域**：必须选择 **中国香港**。
   * **购买时长**：按需选择。
   ![图4-配置选择详情](图4_配置选择详情.png)

5. **确认购买**
   购买完成后，您将在后台看到服务器运行状态。
   ![图5-购买完成界面](图5_购买完成界面.png)

### 1.2 落地 IP 购买

落地 IP 需具备高度纯净性，请通过以下步骤获取并检测。

1. **注册 IP 服务商**
   访问 [兔壳IP (TK-IP)](https://tk-ip.cn/admin.html#/register?invite=fKixxXMV) 注册账号。
   ![图6-服务商后台界面](图6_服务商后台.png)

2. **联系客服测试**
   注册后，联系页面右侧的专属微信客服经理进行 IP 测试。
   ![图7-联系客服及检测结果](图7_联系客服.png)

3. **IP 纯净度检测网址**
   购买后请务必使用以下工具检测（欺诈分/Fraud Score 越低越好）：
   * [Scamalytics](https://scamalytics.com/)
   * [Ping0](https://ping0.cc/)
   * [Whoer](https://whoer.com/zh/)

## 二、 正式搭建步骤

1. **进入远程连接**
   在阿里云控制台 -> 轻量应用服务器 -> 选择您的香港服务器 -> 点击“远程连接”。
   ![图8-远程连接入口](图8_远程连接.png)
   点击“立即登录”。

2. **执行搭建命令**
   在打开的黑色终端（命令行）中，依次执行以下操作：

   * **第一步：获取 Root 权限**
     输入以下命令并回车：
     ```bash
     sudo -i
     ```
   * **第二步：执行一键安装脚本**
     复制以下完整命令并粘贴，然后回车：
     ```bash
     bash <(curl -sL https://raw.githubusercontent.com/v1990901/v2/main/v2v5.sh)
     ```
   ![图9-命令输入示意图](图9_命令输入示意图.png)
